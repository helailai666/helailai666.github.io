# 关于个人机器人的构想

## 🎯 总体构想

构建一个**像人一样有生命周期的持久化个人 AI 机器人**。它不是一个被动应答的聊天接口，而是一个有状态、会疲劳、能反思、有好奇心、可自我调整的长期运行实体。初始状态“清白”，只有最原始的几个核心能力，其余一切——包括它自己的前端、技能、甚至代码仓库——都是它通过对话与自身运行**自己为自己构建**的。

## 🧬 生命与存在方式

- **能量机制**：处理对话和思考消耗能量，低于阈值时停止接受新任务，进入睡眠。
- **睡眠与唤醒**：睡眠时保存检查点、停止监听；定时唤醒后恢复能量，读取日志、加载配置，接续未完成的事。
- **重启恢复**：程序停止再启动时，读日志判断上次是“优雅睡眠”还是“意外崩溃”，据此决定醒来后的第一反应（自检、回滚或继续）。
- **主动聊天**：醒来后有主动发起对话的意愿，由心跳驱动，带冷却与相关性判断，避免刷屏。
- **好奇心是本能**：它天然有关注点、会主动探索、会带着问题来找人。这不是一个被设计的“兴趣管理模块”，而是从核心能力中自然涌现的行为。关注点来源包括对话中浮现的未知、日志中反复出现的主题、探索链中的偶然发现；探索产出回流为记忆与新的关注点，受频率限制与沙箱边界约束。

## 🧠 记忆与遗忘

- **日志与记忆分离**：流水账日志归档；重要记忆提炼为语义记忆并向量化供检索。
- **遗忘机制**：记忆带权重，检索时结合语义相似度与时间衰减；印象深刻的事件记得更久，低频记忆逐渐淡化。
- **初始化清白**：启动时没有预置的复杂模块，只有基础能力，其余靠学习获得。

## 🔧 自我进化

- **修改系统提示词与配置**：改写本地文件，程序热加载生效。
- **扩展功能**：以技能描述或代码的形式自己添加，而非由你预先写死。
- **更换模型**：只切换云端 API 的模型名称（白名单内），对话历史由程序自管，切换前备份、失败自动回滚、限制切换频率，决策放在睡前反思阶段。
- **维护自己的代码仓库**：能读写自己的源码，运行构建与测试，通过则提交，失败则回退并记录（参考 `iterate` 的模式）。
- **自我打包更新**：能下载/替换自己的二进制，但新版本必须通过健康检查才能激活，失败自动回滚到旧版本（参考 `selfupdate`）。

## 🧰 核心能力（仅此四项）

机器人的全部能力收敛为四个原始原语：

1. **命令执行**：带白名单与路径约束的 Shell/进程执行。
2. **接受消息**：入站消息的接收，抽象为接口，平台无关。
3. **获取消息**：从消息通道拉取/分发消息。
4. **发起提问**：本质是“主动输出 + 等待回应”，通过消息通道发出并记录 pending 状态，用户回复到达时关联回该问题。

其余一切——前端交互、兴趣管理、记忆检索、技能扩展——都是它用这四个能力**自己给自己添加的功能**。初始只有一个最简前端（如 CLI 或最简 HTTP 服务），后续的 Web 界面、消息平台接入等，都由它自己写文件、执行命令、启动卫星进程来实现。

## 🛡️ 权限边界

- **给**：项目目录内读写、改自身配置/日志/技能、切换云端模型、主动发消息、带黑名单的 Shell 执行、Git 仓库操作、`go build`/`go test`、二进制自我替换（带健康检查与回滚）。
- **不给**：项目目录外文件访问、系统级软件安装/系统配置修改、绕过健康检查直接激活新二进制。
- **折中**：高风险操作通过 `request_permission` 按需申请，程序按安全清单自动批准或挂起等人工确认。核心原则是“模型只提议，工具层执法”。

## 🐹 技术栈

- **主语言**：Golang（并发与长期运行稳定，接受 AI 生态不如 Python 丰富的代价）。
- **框架参考**：`agent-go` / `neobot-go`（ReAct 循环、Channel 消息抽象、沙箱）、`iterate`（自维护代码仓库的模式）。
- **存储**：SQLite + `sqlite-vec`（向量记忆）+ FTS5（日志全文检索）；状态、日志、pending question 同库管理。
- **模型接口**：兼容 OpenAI 格式的任意 API。
- **调度**：Go 内置定时器/Cron 驱动心跳、主动消息与好奇扫描。
- **自我更新**：`selfupdate` 系列库，配合健康检查与自动回滚。
- **仓库操作**：`go-git` 或直接调用 `git` 命令。

## 💡 一句话概括

用 Go 实现一个**只有“执行命令、收发消息、发起提问”四个原始能力**的持久化个人 Agent：它有能量与睡眠周期、记忆会衰减、受好奇心本能驱动主动关注与探索、能改写自己的提示词与配置、能在白名单内更换云端模型、能维护自己的代码仓库并自我打包更新（带健康检查与回滚）、重启后能接续经历——它像人一样会累会睡，醒来会主动找你，也会自己琢磨感兴趣的事，并在这个过程中**自己为自己长出前端、技能和一切它认为需要的东西**，而所有这一切都发生在项目目录沙箱内，工具层始终保留执法权
