# Python 3.15 RC1 降临：JIT 提速 8-13%、free-threading 转正与 uv 的黄金时代

> **摘要：** 2026年8月4日，Python 官方发布 **3.15.0rc1**（首个候选版，距正式版仅两步）。本轮迭代带来了 JIT 编译器的显著升级（x86-64 提速 8-9%，macOS ARM 提速 12-13%）、free-threading 在官方 macOS 二进制中默认开启，以及 Windows 全面切换到 tail-calling 解释器。与此同时，uv 生态继续攻城略地——8 月最新基准显示其冷安装速度是 pip 的 6 倍。本文深度解读这些变化。

---

## 一、Python 3.15.0rc1：性能之年收官

Python 3.15 于 8 月 4 日进入 RC 阶段，这也是官方确认的**功能冻结点**——从此只修 bug，不再加新特性。3.15.0rc2 计划 9 月 1 日发布，正式版将在秋季（10 月）落地。RC1 的三大看点：

### ⚡ JIT 编译器"肉眼可见"地变快

3.15 的 JIT（即时编译）相比 3.14 的实验版本有了质变：

| 平台 | 性能提升 |
|:----|:--------|
| x86-64 Linux | **8-9%** 几何平均提升（对比标准解释器） |
| AArch64 macOS | **12-13%** 提速（对比 tail-calling 解释器） |

这不再是"实验室数据"——官方 Windows 64 位二进制**已默认采用 tail-calling 解释器**，普通用户装完即享受提速。

### 🧵 free-threading 转正

官方 macOS 二进制现在**默认启用 free-threading 支持**（即无 GIL 模式）。多线程 CPU 密集任务终于能真正利用多核，这是 3.13 提出 free-threading 以来最关键的一步。

### 🎨 其他亮点

- **lazy imports（PEP 810）**：显式惰性导入，启动加速
- **profiling 模块（PEP 799）**：标准库级高性能采样分析器，可附加到运行进程
- **frozendict（PEP 814）**：真正的不可变字典
- **UTF-8 默认编码**：彻底告别平台编码差异
- 改进的错误信息 + 更多颜色输出

> 💡 **业界反馈**：Hacker News 上开发者评价 "Python 现在用 UTF-8 作为默认编码，是代码评审中最高频问题的解药"。

## 二、uv：从"新贵"到"默认标配"

8 月最新基准数据（PyObfuscate，2026-08）显示，冷安装 31 个依赖：

```
uv:   7.90 秒
pip:  47.26 秒
差距: ~6 倍（缓存未命中情况下）
```

uv 目前 **约 2800 万月下载量**，已占 PyPI 流量的两位数百分比，GitHub Stars 突破 85k。其"一把梭"定位——取代 pip + pip-tools + virtualenv + pyenv + pipx + Poetry——正在成为现实。

### 🔐 安全发布：Trusted Publishing 成为标配

2026 年的最佳实践是**不再在 CI 中存储 PyPI Token**：通过 GitHub Actions 的 OIDC 短时令牌 + `uv publish`，实现"无密钥发布"。这大幅降低了供应链泄露风险。

### 🌊 行业地震的余波

3 月 OpenAI 收购 Astral（uv/Ruff/ty 母公司）的余波仍在发酵。Simon Willison 等社区领袖持续关注：开源工具被商业 AI 巨头收购后，治理独立性与长期路线图如何保证？目前 Astral 承诺"继续开源建设"，但这一话题将是 Python 生态下半年的核心看点。

## 三、生态日历：DjangoCon 与打包治理

- **DjangoCon US 2026**：8月24-28日，芝加哥（正在进行中）
- **PEP 772**：Packaging Council（打包委员会）已建立，打包生态治理走向制度化
- **3.14.5 小版本**：回滚了增量 GC 到 3.13 世代收集器（应对生产内存压力报告），提醒我们"新特性未必总是更好"

## 四、总结

| 维度 | 2025 年 | 2026 年 8 月 |
|:----|:--------|:------------|
| 解释器 | 标准解释器 | **tail-calling + JIT（8-13% 提速）** |
| 多线程 | GIL 限制 | **free-threading 默认开启（macOS）** |
| 包管理 | pip 主导 | **uv 6 倍速 + OIDC 可信发布** |
| 发布安全 | token 存储 | **Trusted Publishing 无密钥** |

> **一句话总结：** Python 3.15 RC1 用实打实的 JIT 提速与 free-threading 转正宣告"Python 可以很快"，而 uv 生态则用 6 倍速与无密钥发布宣告"Python 工具链不再痛苦"。秋天，值得期待。
