## 一、常用总结

### 1. 添加新页面

```bash
hugo new content/posts/my-first-post.md
```

### 2. 编译更新前端代码

```bash
hugo --config hugo.toml build -D
```

### 3. 前端代码推送

```bash
cd public
git add .
git commit -m "hugo study 01"
git push origin main
cd ..
```
